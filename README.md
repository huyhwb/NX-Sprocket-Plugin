# NX 12.0 链轮生成插件

Siemens NX 12.0 的参数化链轮生成插件。用 NX 自带对话框（Block UI Styler）输入参数，
按 ISO 606 三段弧齿形生成链轮轮廓，再拉伸成实体并完成中心孔、螺丝孔、沉孔、倒角。

> 部署到其他电脑请先看 **[部署说明.txt](部署说明.txt)**（含必需文件清单与两种配置方式）。
>
> 上传 / 同步到 GitHub 见该文档**第七章**。

## 功能

| 分组 | 参数 | 取值范围 | 默认 |
|---|---|---|---|
| 链条规格 | 链号 | 13 种标准链号 + 自定义 | 08A |
| 齿数 | 齿数 z | 7 ~ 200 | 25 |
| 链轮参数 | 节距 p | 0.1 ~ 1000 | 按链号自动 |
| 链轮参数 | 滚子直径 d1 | 0.01 ~ 500 | 按链号自动 |
| 链轮参数 | 厚度 | 0.5 ~ 200 mm | 10 |
| 链轮参数 | 齿顶圆直径 | 0 ~ 5000（0 = 自动计算） | 0 |
| 中心孔 | 直径 | 0.1 ~ 500 mm | 20 |
| 螺丝孔 | 数量 | 2 ~ 36 | 4 |
| 螺丝孔 | 直径 / 分布圆直径 | 0.1~100 / 1~5000 | 9 / 70 |
| 沉孔 | 直径 / 深度 | 0.1~200 / 0.1~100 | 15 / 5 |
| 倒角 | 轴向长度 | 0.05 ~ 100 mm | 1 |
| 倒角 | 端面长度 | 0.05 ~ 500 mm | 5 |

倒角为**非对称两侧倒角**：一侧长度沿**轴向**（板厚方向）量取，另一侧在**端面**上量取，
默认 **1 × 5**（轴向 1，端面 5）。

**做法是车削加工**（v29 起截面写进草图）：在 **XZ 平面**（y = 0，即含回转轴线的平面）内画一个
**四边形**截面，绕 Z 轴旋转 360° 得到回转体，再与链轮主体**布尔减**。这等价于车床上
车外圆倒角——刀尖沿"轴向 `轴向`、径向 `端面`"的斜线进给，切出来的是**回转面**，与
齿形无关，所以尺寸不受齿廓曲率限制。

**旋转与布尔减是两个独立的特征**（v28 起，与西门子官方样例一致）：旋转只负责造出一个
环形工具体（`BooleanOperation.Type = Create`），布尔减由单独的布尔特征完成
（目标体 = 链轮主体，工具体 = 刚转出来的环）。分成两步的好处是——万一失败，报错能直接
区分是"提交旋转"还是"提交布尔减"。

**上下两个端面都倒**（`z = 板厚` 与 `z = 0` 各做一次），两个截面互为镜像，都画在
**「草图5-倒角轮廓」**里（8 条棱线），然后分别旋转、分别布尔减，两个端面分别报告成功/失败。

> **截面为什么必须是四边形、必须画在 XZ 平面？**（这两个坑都踩过）
>
> - **XZ 平面**：回转轴是 Z 轴，NX 旋转特征要求截面平面包含/平行于回转轴。若把截面
>   写进 `z = 0` 的 XY 平面（与 Z 轴垂直），截面退化，旋转会失败或不生成实体。
> - **四边形**：截面若用三角形，它的平边正好落在端面上、与主体端面**共面**；共面布尔减
>   是这个环境里布尔失败的头号原因（打孔时也踩过）。所以把工具体往端面外多探出 1 mm，
>   多出的部分在空气里，不会多切掉任何东西。

> **出问题怎么定位？** 倒角失败时会报出**步骤标签**，例如
> `步骤[1h 提交旋转（CommitFeature → 独立的工具体）]：内部错误：内存访问违例`，
> 一眼就能看出是哪一句 API 报的，不必再猜。步骤划分：
> `1a 建旋转特征 → 1b 建关联回转轴 → 1c 赋回转轴 → 1d 整圈角度 → 1e 公差 →
> 1f 设截面 → 1g 声明只建新体 → 1h 提交旋转（造出工具体）→
> 2a 取工具体 → 3a 建布尔减 → 3b 设工具体 → 3c 提交布尔减`。

> **v30：回转轴必须用「关联」重载**（这是 v26/v28/v29 三次都崩在提交旋转的真根因）
>
> 旧写法用的是 `Axes.CreateAxis(Point3d, Vector3d, WithinModeling)`。查本机
> `NXBIN\managed\NXOpen.xml`，该重载的注释是 **"Create a non-associative axis"**，
> 参数说明还写着 **"This can only be used by feature update in modeling"** ——
> 也就是说它**只允许在特征更新流程里用**，拿它新建旋转特征时，提交阶段会引用到
> 一个非法/非持久的轴对象，NX 内核直接报内存访问违例。因为崩在"提交"而不是"建轴"，
> 前几版一直被误导成"属性顺序"或"截面"问题。
>
> 正解（与官方 `TelescopeMirrorCore.cpp` 769-776 行、以及 nxjournaling 上实测跑通的
> revolve 脚本一致）是**关联**重载，且要在 `CreateRevolveBuilder` **之后**建：
> `Points.CreatePoint` + `Directions.CreateDirection` → `Axes.CreateAxis(Point, Direction, …)`。
>
> 另外倒角现在有**两条截面路径**：主路径 `CreateRuleCurveDumb`（与已跑通的拉伸完全一致），
> 失败后自动再试备用路径 `CreateRuleBaseCurveDumb(IBaseCurve[])` + 7 参 `AddToSection`
> （官方 .NET 草图样例同款）；两条都失败时会把两条的原因一起报出来，方便一次定位。

> **两条限制**（超出会自动跳过并提示，不会切坏零件）：
>
> - 轴向长度 ≤ 板厚的一半 —— 否则上下两个倒角会连成通槽；
> - 端面长度 ≤ 齿高 —— 端面长度是径向内缩量，超过齿高就会切到轮体。
>
> 对比：v23/v24 用的是 NX 的**边倒角**（ChamferBuilder），要沿每条边的两个相邻面
> 各自偏置。链轮外缘由每齿 4 段弧拼成，08A/z=25 实算齿沟弧半径仅 4.01 mm、齿顶弧宽
> 仅 1.75 mm，偏置量稍大就报"端部条件可能使所有面无法正确相连"—— 几何上做不到，
> 已废弃。

### 模型树里的草图（v29 起）

每次生成都会把用到的曲线装进**命名草图**，方便直接在 NX 里查看/编辑：

| 草图 | 内容 | 平面 | 用途 |
|---|---|---|---|
| 草图1-外形轮廓 | `4z` 段齿廓弧（08A/z=25 为 100 段） | XY（z = 0） | 主体拉伸 |
| 草图2-中心孔 | 1 个整圆 | XY（z = −1） | 拉伸减料 |
| 草图3-螺丝通孔 | 分布圆上 N 个整圆 | XY（z = −1） | **一次**拉伸减料（一次减出全部通孔） |
| 草图4-螺丝沉孔 | 分布圆上 N 个整圆 | XY（z = 0） | 一次拉伸减料（仅勾选沉孔时） |
| 草图5-倒角轮廓 | 8 条棱线（上下两端各 4 条） | XZ（y = 0） | 两次旋转减料 |

> 打孔平面取 **z = −1** 是 v22 的"贯穿裕量"：整圆下移 1 mm、拉伸位移加长 2 mm，
> 工具体两端都超出目标体，避开**共面布尔**（本环境布尔失败的头号原因）。
>
> 草图依附在三个**固定基准面**上（XY@z=0、XY@z=−1、XZ@y=0），位置由插件按上述数值
> 直接给定；模型树里会看到「草图基准面-XY / -XY(-1) / -XZ」这三个基准面，用到才建。
>
> 建草图失败**不会中断生成**（原因写进报错框的「草图：」一行），后续拉伸/旋转仍按
> 原始曲线照常进行。

标准链号（13 种，均为 ISO 606）：

| 链号 | 节距 p (mm) | 滚子直径 d1 (mm) | 链号 | 节距 p (mm) | 滚子直径 d1 (mm) |
|---|---|---|---|---|---|
| 05B | 8.0 | 5.0 | 20A | 31.75 | 19.05 |
| 06B | 9.525 | 6.35 | 24A | 38.1 | 22.23 |
| 08A | 12.7 | 7.95 | 28A | 44.45 | 25.4 |
| 08B | 12.7 | 8.51 | 32A | 50.8 | 28.585 |
| 10A | 15.875 | 10.16 | 40A | 63.5 | 39.68 |
| 12A | 19.05 | 11.91 | 48A | 76.2 | 47.63 |
| 16A | 25.4 | 15.88 | | | |

选「自定义」时不查表，直接使用手输的节距与滚子直径。

## 运行环境

- Siemens NX 12.0（Windows x64）
- **不需要** Visual Studio、.NET SDK，也没有任何编译步骤
  —— 插件是 `.vb` Journal + `.dlx` 对话框，由 NX 在运行时自行加载执行

## 安装

见 [部署说明.txt](部署说明.txt)。最简方式：

1. 双击 `启动NX链轮插件.bat`
2. 打开 NX → 菜单「链轮工具 → Generate Sprocket...」

若想每次启动 NX 都带插件，则设系统环境变量 `UGII_USER_DIR` 为本目录（末尾不要加反斜杠）。

## 使用

1. 启动 NX，新建或打开一个部件文件
2. 菜单「链轮工具 → Generate Sprocket...」
3. 设置参数后点「确定」，插件在当前工作部件中生成链轮实体

## 齿形实现

按 ISO 606 用三段圆弧构造齿形，**每齿 4 段弧**（共 `4z` 段）：

1. **齿沟弧（滚子座）** 半径 `ri = 0.505·d1`，圆心在节圆上
2. **齿面弧（工作弧）** 半径 `re = 0.12·d1·(z + 2)`
3. **齿顶弧** 半径 `da / 2`，圆心在链轮中心

- 齿沟角 `a = 140° − 90°/z`
- 齿顶圆 `da = mean( d + p·(1 − 1.6/z) − d1 , d + p·1.25 − d1 )`，其中 `d = p / sin(π/z)` 为分度圆直径
- 相邻弧的切点用两次海伦公式求三角形高得到
- 每段弧用三点法 `Curves.CreateArc(起点, 弧上点, 终点, False, flipped)` 创建，
  再把 `4z` 条弧整体作为拉伸截面

## 开发说明

- **主要源文件**：`startup\SprocketPlugin.vb`（主程序）、`startup\SprocketPlugin.dlx`（对话框）
- `application\` 下是副本。**改完必须两份同步**，否则可能加载到旧版本
- `.vb` 与 `.dlx` 属于同一功能的两半，必须成对更新
- 对话框 `.dlx` 由 Block UI Styler 编辑/生成；本机另有一套 Python 生成脚本
  （`make_dlx.py` + `gen_sprocket_dlx.py`），改控件后需重新生成并校验
- NX 12.0 的 Journal VB 引擎语法较旧，注意：
  不用 `With` / `Using` / Lambda / 字符串插值 `$"..."`；
  反三角函数写作 `Atan2`（`Atn2` 是 VB6 名称，不存在）
- **失败时用裸 `Throw`，不要用 `Throw ex`** —— 后者会重置异常堆栈，
  把真正出错的 NXOpen 调用帧全部抹掉

### 内置诊断

生成失败时会弹出诊断框，包含四行关键信息（定位问题时请提供全文）：

| 行 | 含义 |
|---|---|
| 阶段 | 卡在哪一步（1/6 查表 → 2/6 算轮廓 → 3/6 主体拉伸 → 4/6 中心孔 → 5/6 螺丝孔 → 6/6 倒角） |
| 轮廓 | 轮廓点数、段数、零点个数、相邻弧缝最大值（正常：零点 0、弧缝约 1E-13 mm） |
| 草图 | 每个草图建了几条曲线；某张草图失败时在这里写明是哪一步、什么原因 |
| 探针 | 截面实际产出的曲线条数（与输入条数比较，判断曲线是否串成闭合链） |
| 实体 | 目标实体的获取来源、返回项数、是否实体、部件内 Body 总数 |

倒角是最后一步，**失败不会中断生成**（不撤销已做出的零件）——会单独弹一个提示框，
并区分是**上端面**还是**下端面**出的问题，附 NX 原始错误与**倒角截面探针**
（用的是哪条截面规则、截面实际收到几条曲线、轴用的是哪一种）。尺寸越界
（轴向 > 板厚一半、端面 > 齿高）时会在提交前直接拦下并说明原因。

## 当前状态

- 已跑通：轮廓生成（`4z` 段弧、精确闭合）+ 主体拉伸 + 中心孔 / 螺丝孔 / 沉孔
- v29：拉伸/旋转用到的曲线全部装进 **草图1 ~ 草图5**（外形轮廓 / 中心孔 / 螺丝通孔 /
  螺丝沉孔 / 倒角轮廓），螺丝孔由"一孔一拉伸"改为"**一张草图一次拉伸**"
  （实测：草图5 已能正常生成）
- **v30**：倒角旋转改用**关联回转轴**（`Axes.CreateAxis(Point, Direction, …)`，
  建在 `CreateRevolveBuilder` 之后）—— 这是 v26/v28/v29 三次崩溃在
  "提交旋转 / 内存访问违例"的**真根因**；旧写法用的 `CreateAxis(Point3d, Vector3d, …)`
  是非关联轴，NXOpen 文档注明只能用于特征更新
- v30：倒角截面加**双路径 + 截面探针**（主 `CreateRuleCurveDumb` /
  备 `CreateRuleBaseCurveDumb(IBaseCurve[])`），失败时两条原因一并报出
- 倒角为**车削式**：XZ 平面画四边形截面 → 绕 Z 轴 360° 旋转出环形工具体 →
  **单独的布尔减特征**切掉（旋转与布尔拆成两个特征，对齐官方样例），
  **上下两个端面都倒**，回转面与齿形无关，默认 1 × 5（v23/v24 的逐边倒角方案已废弃）
- 倒角失败时按**步骤标签**报错，可直接定位到具体 API 调用（例如 `1h 提交旋转` / `3c 提交布尔减`）
- 版本变更记录见 `startup\SprocketPlugin.vb` 文件头
