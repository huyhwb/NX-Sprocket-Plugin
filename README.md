# NX 12.0 链轮生成插件

Siemens NX 12.0 的参数化链轮生成插件。用 NX 自带对话框（Block UI Styler）输入参数，
按 ISO 606 三段弧齿形生成链轮轮廓，再拉伸成实体并完成中心孔、螺丝孔、沉孔、倒角。

> 部署到其他电脑请先看 **[部署说明.txt](部署说明.txt)**（含必需文件清单与两种配置方式）。
>
> 上传 / 同步到 GitHub 见该文档**第七章**；日常更新可直接双击「推送到GitHub.bat」。

## 运行环境

- Siemens NX 12.0（Windows x64）
- **不需要** Visual Studio、.NET SDK，也没有任何编译步骤
  —— 插件是 `.vb` Journal + `.dlx` 对话框，由 NX 在运行时自行加载执行

## 安装

见 [部署说明.txt](部署说明.txt)。最简方式：

1. 双击 `启动NX链轮插件.bat`
2. 打开 NX → 菜单「链轮工具 → Generate Sprocket...」

若想每次启动 NX 都带插件，则设系统环境变量 `UGII_USER_DIR` 为本目录（末尾不要加反斜杠）。

## 使用

1. 启动 NX，新建或打开一个部件文件
2. 菜单「链轮工具 → Generate Sprocket...」
3. 设置参数后点「确定」，插件在当前工作部件中生成链轮实体

## 齿形实现

按 ISO 606 用三段圆弧构造齿形，**每齿 4 段弧**（共 `4z` 段）：

1. **齿沟弧（滚子座）** 半径 `ri = 0.505·d1`，圆心在节圆上
2. **齿面弧（工作弧）** 半径 `re = 0.12·d1·(z + 2)`
3. **齿顶弧** 半径 `da / 2`，圆心在链轮中心

- 齿沟角 `a = 140° − 90°/z`
- 齿顶圆 `da = mean( d + p·(1 − 1.6/z) − d1 , d + p·1.25 − d1 )`，其中 `d = p / sin(π/z)` 为分度圆直径
- 相邻弧的切点用两次海伦公式求三角形高得到
- 每段弧用三点法 `Curves.CreateArc(起点, 弧上点, 终点, False, flipped)` 创建，
  再把 `4z` 条弧整体作为拉伸截面

## 开发说明

- **主要源文件**：`startup\SprocketPlugin.vb`（主程序）、`startup\SprocketPlugin.dlx`（对话框）
- `application\` 下是副本。**改完必须两份同步**，否则可能加载到旧版本
- `.vb` 与 `.dlx` 属于同一功能的两半，必须成对更新
- 对话框 `.dlx` 由 Block UI Styler 编辑/生成；本机另有一套 Python 生成脚本
  （`make_dlx.py` + `gen_sprocket_dlx.py`），改控件后需重新生成并校验
- NX 12.0 的 Journal VB 引擎语法较旧，注意：
  不用 `With` / `Using` / Lambda / 字符串插值 `$"..."`；
  反三角函数写作 `Atan2`（`Atn2` 是 VB6 名称，不存在）
- **失败时用裸 `Throw`，不要用 `Throw ex`** —— 后者会重置异常堆栈，
  把真正出错的 NXOpen 调用帧全部抹掉

### 内置诊断

生成失败时会弹出诊断框，包含四行关键信息（定位问题时请提供全文）：

| 行 | 含义 |
|---|---|
| 阶段 | 卡在哪一步（1/6 查表 → 2/6 算轮廓 → 3/6 主体拉伸 → 4/6 中心孔 → 5/6 螺丝孔 → 6/6 倒角） |
| 轮廓 | 轮廓点数、段数、零点个数、相邻弧缝最大值（正常：零点 0、弧缝约 1E-13 mm） |
| 探针 | 截面实际产出的曲线条数（与输入条数比较，判断曲线是否串成闭合链） |
| 实体 | 目标实体的获取来源、返回项数、是否实体、部件内 Body 总数 |
